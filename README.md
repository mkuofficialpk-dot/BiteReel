# 🍔 BiteReel

A full-stack social food discovery & delivery platform combining Instagram-style food reels with Zomato-style food ordering.

## 🚀 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Auth:** JWT Authentication
- **Tools:** Git, REST APIs

## ✨ Features

- Instagram-style vertical food video reels
- Restaurant & food partner listings
- User food ordering flow
- JWT-based authentication system
- Production-level MVC architecture

## ⚙️ Installation

```bash
# Clone the repo
git clone https://github.com/mkuofficialpk-dot/BiteReel.git

# Install backend dependencies
cd backend
npm install

# Run the server
npm start
```
